XGBoost — Dataset Split

  • Total Dataset: 578 patients (214 positive PMOS cases, 364 negative cases)
  • Training Set (70%): 404 patients (150 positive, 254 negative) — Used to train the XGBoost model
  • Test Set (30%): 174 patients (64 positive, 110 negative) - Used to evaluate final model performance on unseen data
  • Why this split: Stratified split ensures both datasets have the same proportion of positive/negative cases, preventing bias and providing reliable performance estimates

Test Set Performance Metrics

  • AUC-PR Score (96.20%): Area Under the Precision-Recall Curve. Measures model performance for imbalanced datasets, balancing precision (false alarms) and recall (missed cases).
  • Accuracy (95.40%): Overall correctness of the model. Percentage of all predictions (both positive and negative) that were correct.
  • Precision (92.40%): Of all patients the model flagged as having PMOS, how many actually had it. High precision minimizes unnecessary testing.
  • Recall (95.30%): Of all patients who actually have PMOS, how many did the model correctly identify. High recall minimizes missed diagnoses.
  • F1 Score (93.85%): Harmonic mean of Precision and Recall. Balances both metrics, providing a single score for overall model performance.
  • Clinical Interpretation: The model achieves 95.40% overall accuracy on the test set, correctly identifying 95.30% of actual PMOS cases while maintaining only 7.60% false positives (flagging 5 out of 110 healthy patients incorrectly). This balance makes it clinically reliable for detection.

Test Set Confusion Matrix

  • What this shows: Performance on the held-out test set (30% of total 578 cases), representing real-world model performance on unseen data.
  • True Positive (TP): Patients with the condition correctly identified by the model on the test set.
  • False Positive (FP): Healthy patients incorrectly flagged as having the condition on the test set.
  • False Negative (FN): Patients with the condition that the model missed on the test set.
  • True Negative (TN): Healthy patients correctly identified as not having the condition on the test set.

Stratified 10-Fold Cross-Validation

Folds: 10 Validation Strategy: Stratified Primary Metric: AUC-PR
  • What this measures: This chart shows how consistently the AI model performs when tested on different patient groups.
  • Stratified 10-Fold: The patient dataset was divided into 10 equal groups, ensuring each group has the same proportion of positive/negative cases (like a doctor ensuring diversity in clinical trials).
  • The purple bars: Show the model's AUC-PR performance score on each test group (ranging 89.90% to 99.80%). Higher values mean better diagnostic accuracy.
  • Why important: Consistent high performance across all folds indicates the model works reliably on diverse patient data, not just lucky on one group.

Stratified 10-Fold CV: Confusion Matrix (Global)

  • What is a Confusion Matrix: A confusion matrix is a table that summarizes the performance of a diagnostic model by comparing predicted outcomes against actual outcomes. It reveals not just how many cases the model got right, but specifically which types of errors it makes helping clinicians understand the model's reliability for their specific use case.
  • What this shows: Aggregated diagnostic results across all 10 patient groups from 578 total cases, showing how the model classified each outcome.
  • True Positive (TP - 190): Patients who are PMOS Positive correctly identified by the model. High numbers indicate good disease detection.
  • False Positive (FP - 33): PMOS Negative patients incorrectly flagged as having the condition (false alarms). These lead to unnecessary testing and patient anxiety.
  • False Negative (FN - 24): Patients who are PMOS Positive that the model missed and has been classified as negative. This is clinically the most concerning error type as it delays treatment.
  • True Negative (TN - 331): PMOS Negative patients correctly identified as not having the condition.
  • Clinical interpretation: Overall accuracy is 90.10% with sensitivity of 88.80% and specificity of 91.00%. Priority should be reducing the 24 false negatives to prevent missed diagnoses.
